Part 1 • The Core Mental Model

When someone asks: “Wait… what actually IS an Agent?”

The easiest way to explain it: A standard chatbot is a brain in a jar—it can only talk based on what it memorized. An AI Agent is a teammate with hands, a browser, and a workspace—it can reason, call tools, check its own work, and create real files, images, code, or videos.

💬

Standard Chatbot (LLM Only)

Passive responder • Single pass • Text in, text out

Talks About Work
  • ❌Guesses math & dates instead of running a calculator or live search.
  • ❌One-shot answer: Gives you text and stops immediately.
  • ❌No hands: Cannot run code, verify URLs, or generate multi-step files.
Prompt: “Is coffee pricier in Tokyo or Singapore right now? Show me a chart.”
“Based on my training data, Tokyo coffee is generally ¥500 and Singapore is around S$6. Here is ASCII text representing a chart...” (No live data, no real chart).
🤖

Gemini Antigravity Agent

Goal-driven • Multi-step loop • Uses real tools

Does The Work
  • ✅Uses Live Tools: Searches the web, reads URLs, runs Python/bash in a sandbox.
  • ✅Self-Correcting Loop: If a script or search fails, it sees the error and fixes it.
  • ✅Multimodal & Multi-Agent: Spawns subagents, generates images & Veo 3.1 videos.
Same Prompt → Antigravity Execution Loop:
1️⃣ search_web: Pulls today’s live specialty coffee prices & JPY/SGD FX rate.
2️⃣ run_command: Runs Python in sandbox to compute exact PPP comparison.
3️⃣ generate_image: Renders a clean infographic & attaches it inline!

For Business Stakeholders (Natural Language)

Give your agent a clear job title and personality! Instead of saying “help me with pitches,” say: “You are a ruthless but constructive Shark Tank Venture Capitalist who obsesses over unit economics and memorable hooks.”

For Builders (Google Antigravity SDK)
from google.antigravity import LocalAgentConfig
from google.antigravity.types import TemplatedSystemInstructions

config = LocalAgentConfig(
    model="gemini-3.7-flash",
    system_instructions=TemplatedSystemInstructions(
        identity="You are a Shark Tank VC coach..."
    ),
)
